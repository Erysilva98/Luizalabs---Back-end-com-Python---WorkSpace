# Bootcamp Luizalabs — Back-end com Python

Repositório dedicado aos desafios práticos do bootcamp **Luizalabs — Back-end com Python**, oferecido pela [DIO](https://www.dio.me/).

Cada desafio é mantido como um projeto independente, com código-fonte, documentação técnica e instruções próprias de execução. Essa organização facilita a navegação pelo repositório e permite acompanhar a evolução dos estudos ao longo do bootcamp.

## Desafios

| Nº | Projeto | Descrição | Status |
|---:|---|---|:---:|
| 01 | [Otimizando o Sistema Bancário com Funções Python](./01-sistema-bancario-com-funcoes/) | Refatoração de um sistema bancário procedural, com modularização das operações e cadastro de clientes e contas. | Em desenvolvimento |

> Novos desafios serão adicionados a esta tabela conforme o andamento do bootcamp.

## Estrutura do repositório

```text
.
├── 01-sistema-bancario-com-funcoes/
│   ├── README.md
│   └── src/
│       └── main.py
└── README.md
```

Cada desafio fica diretamente na raiz do repositório e segue a convenção `NN-nome-do-desafio`. Cada diretório contém:

- `README.md`: documentação, requisitos e instruções do desafio;
- `src/`: código-fonte da solução;
- outros diretórios poderão ser incluídos conforme a necessidade de cada projeto.

## Como executar um projeto

Entre no diretório do desafio desejado, consulte seu `README.md` e execute os comandos indicados. Para o primeiro desafio:

```bash
cd 01-sistema-bancario-com-funcoes
python src/main.py
```

## Tecnologias

- Python 3

O bootcamp aborda fundamentos e práticas de desenvolvimento back-end com Python por meio de conteúdos teóricos e desafios de projeto. Este repositório registra as soluções desenvolvidas durante essa jornada.
